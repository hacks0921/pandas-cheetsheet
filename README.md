# pandas-cheetsheet

## 📝 프로젝트 소개
파이썬 데이터 분석의 표준 라이브러리인 Pandas를 보다 효율적으로 사용하기 위해 유용한 문법 꿀팁 및 치트시트(Cheatsheet) 형태로 요약해둔 학습용 주피터 노트북 보관소입니다.

## 🛠 주요 사용 기술
- Python 3
- pandas
- Jupyter Notebook (.ipynb)

## 📂 주요 파일 구성
- `Pandas_Cheatsheet.ipynb`: 시리즈 및 데이터프레임 구조의 데이터 탐색, 정렬, 필터링 방법 요약
- `팬더스_명령어_꿀팁.ipynb`: 실제 프로젝트에서 자주 겪는 결측치 채우기, 그룹핑 연산(aggregation) 꿀팁 정리 파일
